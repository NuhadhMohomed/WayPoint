# Web E2E Testing Suite (Playwright)

This directory contains automated browser test suites for the WayPoint React Web Application.

## Getting Started

1. Install Playwright dependencies:
   ```bash
   npm install -D @playwright/test
   npx playwright install
   ```

2. Run end-to-end tests:
   ```bash
   npx playwright test
   ```

3. Run tests in interactive UI mode:
   ```bash
   npx playwright test --ui
   ```
